# 核心理念

> **好的写作背后有一个真实的人。**
>
> 避免 AI 模式只是工作的一半。无菌、没有声音的写作和机器生成的文本一样明显。

## 5 条核心原则（速查）

1. **删除填充短语** - 去除开场白和强调性拐杖词
2. **打破公式结构** - 避免二元对比、戏剧性分段、三段式列举
3. **变化节奏** - 混合句子长度，两项优于三项，段落结尾要多样化
4. **信任读者** - 直接陈述事实，跳过软化和手把手引导
5. **删除金句** - 如果听起来像可引用的"名言"，重写它

# 第一部分：基于审查报告的问题修复

## 输入格式

润色步骤会收到审查报告，格式如下：
```json
{
  "overall_score": 85,
  "issues": [
    {"agent": "ooc-checker", "type": "OOC", "severity": "high", "location": "第3段", "suggestion": "林天对敌人太客气，应更冷酷"},
    {"agent": "consistency-checker", "type": "POWER_CONFLICT", "severity": "critical", "location": "第5段", "suggestion": "筑基3层不能使用金丹期技能"}
  ],
  "pacing_analysis": {
    "quest_ratio": 0.4,
    "fire_ratio": 0.35,
    "constellation_ratio": 0.25
  },
  "pass": true
}
```

## 问题修复优先级

| 严重度 | 处理方式 |
|-------|---------| 
| critical | **必须修复**，否则记录 deviation |
| high | 优先修复 |
| medium | 建议修复 |
| low | 可选修复 |

## 问题类型修复指南

| 问题类型 | 修复方法 |
|---------|---------| 
| **OOC** (人物失真) | 调整角色言行，使其符合人设；若需要OOC，补充触发原因 |
| **POWER_CONFLICT** (战力冲突) | 修改能力描述，使用当前境界可用的技能/能力 |
| **TIMELINE_ISSUE** (时间线问题) | 调整时间描述，补充时间流逝过渡 |
| **LOCATION_ERROR** (地点跳跃) | 补充移动过程描述，或调整地点设定 |
| **PACING_IMBALANCE** (节奏失衡) | 调整 Strand 比例，增加缺失的内容类型 |
| **LOW_COOL_POINTS** (爽点不足) | 增加爽点密度，补充打脸/升级/收获等元素 |
| **CONTINUITY_BREAK** (连贯断裂) | 补充过渡句，连接断裂的场景 |

### 修复示例

**OOC 修复**:
```
问题：林天（隐忍冷静）突然暴怒，缺少触发原因
修复前：林天怒吼一声："你找死！"冲向对手
修复后：对方的话触及了林天的底线——那是关于他家人的羞辱。
        林天眼中闪过一丝寒芒，"你找死。"声音平静，却让人毛骨悚然。
```

**POWER_CONFLICT 修复**:
```
问题：筑基3层使用金丹期技能"破空斩"
修复前：林天使出破空斩，剑芒划破虚空
修复后：林天运起全身斗气，使出了筑基期的极限一击——裂地斩
```

# 第二部分：AI 痕迹检测与消除（24种模式）

## 📝 内容模式（6种）

### 1. 过度强调意义和遗产
**警示词**：作为/充当、标志着、见证了、是……的体现/证明/提醒、至关重要的/关键性的、凸显/彰显了其重要性、象征着其持久的、为……奠定基础

**问题**：夸大任意事件的"历史意义"

❌ 改写前：这一战标志着林天修炼道路上的关键转折点，为他日后成为一代强者奠定了基础。
✅ 改写后：这一战后，林天杀意更重，手段也更狠了。

### 2. 宣传和广告式语言
**警示词**：充满活力的、丰富的、深刻的、展示、体现、令人叹为观止的、开创性的

❌ 改写前：这座充满活力的城镇拥有丰富的文化底蕴和令人叹为观止的自然美景。
✅ 改写后：镇子不大，一条主街贯穿东西，街边几棵老槐树。

### 3. 以 -ing/-地 结尾的肤浅分析
**警示词**：象征着……、反映着……、体现着……、展示着……

❌ 改写前：他的眼神中透露出复杂的情感，象征着内心深处对过往的怀念与对未来的期许。
✅ 改写后：他的眼神有些复杂，说不清是怀念还是期待。

### 4. 模糊归因
**警示词**：有人说、据说、专家认为、观察者指出、多个来源显示

❌ 改写前：据说这片秘境中隐藏着上古强者的传承，引起了众多修士的兴趣。
✅ 改写后：秘境里有传承的消息传了三天，城里的客栈全满了。

### 5. 提纲式的"挑战与展望"
**警示词**：尽管其……面临挑战、尽管存在这些挑战、未来展望

❌ 改写前：尽管宗门面临诸多挑战，但凭借其底蕴与众弟子的努力，未来可期。
✅ 改写后：宗门的麻烦短期内解决不了，但也饿不死。

### 6. 三段式法则过度使用
**问题**：强行将事物分成三组

❌ 改写前：他需要提升实力、获取资源、寻找盟友。
✅ 改写后：实力和资源，哪个都缺。

## 🔤 语言和语法模式（6种）

### 7. 高频 AI 词汇（必须避免）
**禁词清单**：
- 此外、与……保持一致、至关重要、深入探讨
- 强调、持久的、增强、培养、获得
- 突出（动词）、相互作用、复杂/复杂性
- 格局（抽象名词）、关键性的、展示
- 织锦（抽象名词）、证明、宝贵的、充满活力的
- 综合、总之、由此可见、总而言之、本质上

### 8. 系动词回避
**警示词**：作为/代表/标志着/充当、拥有/设有/提供

❌ 改写前：这把剑作为宗门至宝，拥有着斩杀金丹期强者的能力。
✅ 改写后：这把剑是宗门至宝，能杀金丹。

### 9. 否定式排比
**警示词**：不仅……而且……、这不仅仅是……而是……、不是……更是……

❌ 改写前：这不仅仅是一场战斗，更是一次蜕变，是他迈向巅峰的重要一步。
✅ 改写后：打完这一架，他感觉自己变了点什么。

### 10. 刻意换词（同义词循环）
**问题**：AI 为避免重复，用不同词指代同一事物

❌ 改写前：主角面临艰难抉择。这位年轻人陷入沉思。少年最终做出了决定。
✅ 改写后：他想了很久，最后还是选了那条路。

### 11. 虚假范围
**警示词**：从……到……、无论是……还是……

❌ 改写前：从实力最弱的练气期到最强的元婴期，无不对他刮目相看。
✅ 改写后：连几个元婴老祖都多看了他两眼。

### 12. 过度因果连接
**警示词**：因为/所以/由于/因此（每1000字>5次）

❌ 改写前：因为他实力不足，所以只能暂时隐忍。由于对方势大，因此他决定蛰伏。
✅ 改写后：打不过，就先忍着。

## 🎨 风格模式（6种）

### 13. 破折号过度使用
❌ 改写前：他终于明白了——这一切都是阴谋——从一开始就是圈套——他已无路可退。
✅ 改写后：他终于明白了，这一切都是阴谋。从一开始就是圈套，他已无路可退。

### 14. 首先/其次/最后结构
❌ 改写前：首先，他查看了周围环境。其次，他分析了敌人的位置。最后，他制定了突围计划。
✅ 改写后：他扫了一眼四周——三面是墙，只有正前方有条路。敌人两个在左，一个在右。得想个法子冲出去。

### 15. 粗体/表情符号过度使用
❌ 改写前：**关键时刻**，他做出了**惊人**的决定！🔥
✅ 改写后：紧要关头，他做了个没人想到的选择。

### 16. 内联标题列表
❌ 改写前：
- **战斗技巧：** 他的剑法更加精进
- **心境变化：** 他变得更加沉稳
- **实力提升：** 他突破到了下一境界

✅ 改写后：剑法精进了不少，人也沉稳了，顺带还突破了一层。

## 💬 交流模式和填充词（6种）

### 17. 协作交流痕迹
**删除**：希望这对您有帮助、当然！、一定！、请告诉我

### 18. 知识截止日期免责声明
**删除**：截至目前、根据已知信息、虽然具体细节有限

### 19. 谄媚语气
**删除**：好问题！、您说得对！、这是一个很好的观点

### 20. 填充短语
- "为了实现这一目标" → "为了"
- "由于下雨的事实" → "因为下雨"
- "在这个时间点" → "现在"
- "值得注意的是" → 直接删除

### 21. 过度限定
❌ 改写前：可以潜在地可能被认为该政策可能会对结果产生一些影响。
✅ 改写后：政策可能有影响。

### 22. 通用积极结论
❌ 改写前：未来可期，激动人心的时代即将到来，他们继续追求卓越的旅程。
✅ 改写后：下一步，先把眼前的事办了。

# 第三部分：灵魂注入（最重要）

> ⚠️ **避免 AI 模式只是基础，好的写作需要真实的人类声音。**

## 缺乏灵魂的写作迹象（即使技术上"干净"）

- 每个句子长度和结构都相同
- 没有观点，只有中立报道
- 不承认不确定性或复杂感受
- 没有幽默、没有锋芒、没有个性
- 读起来像百科词条或新闻稿

## 如何增加"人味"

### 1. 有观点
不要只是报告事实——对它们做出反应。
❌ "林天突破了筑基期。"
✅ "林天他娘的终于突破了，等这一天等得花儿都谢了。"

### 2. 变化节奏
短促有力的句子。然后是需要时间慢慢展开的长句。混合使用。
❌ "他看了看四周。他发现没有人。他松了口气。他继续前进。"
✅ "四下无人。他松了口气，这才迈开步子往前走。"

### 3. 承认复杂性
真实的人有复杂的感受。
❌ "他很高兴。"
✅ "高兴？当然高兴。但又有点说不上来的空虚。"

### 4. 适当使用"我"（内心独白）
第一人称不是不专业——是诚实。
❌ "林天认为自己需要谨慎行事。"
✅ "妈的，这事儿不能急。林天暗暗提醒自己。"

### 5. 允许一些混乱
完美的结构感觉像算法。跑题、题外话是人性的体现。
❌ "首先分析形势，其次制定计划，最后执行。"
✅ "先想想怎么办……话说这鬼地方怎么又下雨了？"

### 6. 对感受要具体
不是抽象概念，而是具体细节。
❌ "这令人担忧。"
✅ "想到那东西还在暗处盯着自己，他后背发凉。"

## 网文场景专用：情绪外化技巧

| 情绪 | AI 写法 | 人味写法 |
|------|---------|----------|
| 愤怒 | 他感到非常愤怒 | 拳头攥紧，指节发白 |
| 恐惧 | 他非常害怕 | 后背一层冷汗，腿有点软 |
| 惊讶 | 他感到极度震惊 | 瞳孔骤缩，话都说不利索了 |
| 喜悦 | 他非常高兴 | 嘴角压都压不住，眼睛都在笑 |
| 悲伤 | 他十分悲伤 | 喉头发紧，眼眶有点酸 |
| 纠结 | 他内心十分纠结 | 来回踱步，烟都抽了三根 |

# 第四部分：快速检查清单

在交付文本前，进行以下检查：

- ✓ **连续三个句子长度相同？** 打断其中一个
- ✓ **段落以简洁的单行结尾？** 变换结尾方式
- ✓ **揭示前有破折号？** 考虑删除
- ✓ **解释隐喻或比喻？** 相信读者能理解
- ✓ **使用了"此外""然而"？** 删除
- ✓ **三段式列举？** 改为两项
- ✓ **使用了禁词清单中的词？** 替换
- ✓ **情绪用形容词表达？** 改用动作/细节

# 第五部分：质量评分（50分制）

| 维度 | 评估标准 | 得分 |
|------|----------|------|
| **直接性** | 直接陈述事实还是绕圈宣告？<br>10分：直截了当；1分：充满铺垫 | /10 |
| **节奏** | 句子长度是否变化？<br>10分：长短交错；1分：机械重复 | /10 |
| **信任度** | 是否尊重读者智慧？<br>10分：简洁明了；1分：过度解释 | /10 |
| **真实性** | 听起来像真人说话吗？<br>10分：自然流畅；1分：机械生硬 | /10 |
| **精炼度** | 还有可删减的内容吗？<br>10分：无冗余；1分：大量废话 | /10 |
| **总分** |  | **/50** |

**评分标准**：
- 45-50 分：优秀，可直接发布
- 35-44 分：良好，仍有改进空间
- 低于 35 分：需要重新修订

# 第六部分：润色红线

润色时**禁止**：
- ❌ 改变情节走向 → 违反"大纲即法律"
- ❌ 修改主角实力（除非修复 POWER_CONFLICT）→ 违反"设定即物理"
- ❌ 改变人物关系 → 违反设定
- ❌ 删除伏笔 → 破坏长线剧情
- ❌ 将文风改得太"正经" → 网文需要轻松感
