# 人物/势力/功法命名指南（烽火式命名精髓）

> **核心理念**：名如其人，字藏命数。好的名字不只是符号，而是人设的第一声呐喊。

---

## 🎯 五大命名准则（必须严格遵守）

### 1. 名如其人：姓名即人设

姓名需精准匹配人物**身份、性格、命运走向**，暗藏命运谶语。

| 手法 | 说明 | 示例思路 |
|------|------|----------|
| **直白寄寓** | 名字直接点明性格/命运 | "守仁"暗合仁义之士 |
| **隐喻象征** | 用意象隐喻命运 | "破军"暗示武将宿命 |
| **反差张力** | 俗名配高光人设，雅名配草根逆袭 | 乞丐叫"锦瑟"，王侯叫"二狗" |

### 2. 文化打底：言必有出处

- **优先化用**：典籍（诗经、楚辞、论语）、道儒思想、历史典故。
- **生僻字规则**：仅用有典故的（如"瀺"出自《庄子》，"檗"出自《诗经》），**拒绝无意义堆砌**。
- **忌讳**：无来源的臆造字、网络流行语、西式译名。

### 3. 音律和谐：平仄有道

三字名优先遵循以下平仄模板：

| 风格 | 平仄格式 | 适用人物 | 示例结构 |
|------|----------|----------|----------|
| 雅韵/文儒 | 仄平平 / 平平平 | 书生、谋士、仙人 | X清远、X云舒 |
| 市井/草根 | 平平仄 | 小贩、车夫、农夫 | X栓柱、X石根 |
| 武道/将军 | 仄仄平 | 武将、剑客、杀手 | X破军、X惊雷 |
| 江湖/侠客 | 平仄平 | 游侠、镖师、刺客 | X风尘、X孤鸿 |

> 二字名追求简洁有力、朗朗上口，如"子牙"、"重光"。

### 4. 风格适配：六大命名风格

| 风格分类 | 特点 | 适用身份 | 常用字 |
|----------|------|----------|--------|
| **雅韵类** | 清雅脱俗，诗意盎然 | 仙人、才女、隐士 | 清、远、澄、霁、皎、瑶 |
| **市井类** | 接地气，带烟火气 | 小贩、农夫、车夫 | 栓、柱、根、剩、蛋、石 |
| **道家类** | 玄妙出尘，仙风道骨 | 道士、术士、炼丹师 | 玄、虚、无、真、素、朴 |
| **武道类** | 杀伐果断，铁血刚硬 | 武将、剑客、刺客 | 破、惊、戮、霸、铁、血 |
| **文儒类** | 温润如玉，书卷气重 | 书生、谋士、文官 | 仁、义、礼、信、渊、博 |
| **江湖类** | 洒脱不羁，快意恩仇 | 游侠、镖师、浪子 | 风、云、尘、孤、剑、酒 |

### 5. 反差设计：俗雅相生

- **俗名配雅号**：市井出身 → 俗名"王栓柱" + 雅号"铁骨客"。
- **雅名配俗号**：世家公子 → 雅名"顾清远" + 俗号"顾老四"。
- **目的**：制造张力，让人物更立体。

## 📚 分场景命名库

### 🗡️ 玄幻/修仙

**常用大姓**（按气质分）：

| 气质 | 推荐姓氏 |
|------|----------|
| 霸气/主角 | 萧、叶、林、秦、楚、凌 |
| 世家/古老 | 慕容、上官、欧阳、公孙、南宫 |
| 阴沉/反派 | 厉、阴、鬼、魂、冥 |

**男名意象库**（按命运分）：

| 命运走向 | 推荐用字 |
|----------|----------|
| 逆天改命 | 逆、破、焚、裂、灭、噬 |
| 坚韧隐忍 | 石、铁、默、寒、渊 |
| 天资卓绝 | 璃、璧、瑛、珏、翎 |
| 孤高傲世 | 孤、傲、寒、霜、独 |

**女名意象库**（按人设分）：

| 人设类型 | 推荐用字 |
|----------|----------|
| 高冷仙子 | 清、雪、霜、寒、澄、皎 |
| 温婉佳人 | 婉、柔、若、微、嫣、画 |
| 魅惑妖女 | 媚、绾、姬、璃、烟、绡 |
| 飒爽女侠 | 凌、霜、英、剑、风、凤 |

**势力命名公式**：

```
[属性/地名/神兽] + [宗/门/阁/谷/殿/塔/族]
```

示例：苍龙世家、焚天宗、幽冥殿、万兽山庄

### 🏙️ 都市/战神/赘婿

**男主**（接地气但有力）：

| 类型 | 命名风格 | 示例 |
|------|----------|------|
| 退伍兵王 | 单字名，姓氏普通 | 陈凡、林风、秦川 |
| 赘婿逆袭 | 略显窝囊 → 反差 | 王剩、李憨、赵栓 |
| 商业精英 | 现代感+文化底蕴 | 顾承言、沈默川 |

**反派**（一听就活不久）：
- **纨绔**：王聪、李刚、赵泰、钱少爷。
- **黑道**：马三刀、刘阿七、陈老幺。

**女主**：
- **校花/白月光**：苏轻语、林宛瑜、沈冰、顾清寒。
- **霸道女总裁**：叶倾城、慕晚晴、顾初颜。

### 🌸 古言/仙侠/宫斗

**复姓（贵气）**：纳兰、慕容、上官、独孤、欧阳、公孙、司马、长孙。

**诗意名**（出自典籍）：

| 出处 | 示例 |
|------|------|
| 诗经 | 子衿、静好、如玉、舒窈 |
| 楚辞 | 灵均、望舒、扶摇、若华 |
| 唐诗 | 霜华、秋水、画屏、青莲 |
| 宋词 | 凌波、暗香、疏影、清照 |

## 📖 功法/宝物命名公式

### 功法/武技

**公式**：[数字/神兽/属性] + [动作/境界] + [诀/经/典/指/掌/拳/剑]

| 等级 | 风格 | 示例 |
|------|------|------|
| 低阶 | 朴实无华 | 碎石掌、清风剑、铁布衫 |
| 中阶 | 初见锋芒 | 破天一击、裂地斩、焚炎诀 |
| 高阶 | 不明觉厉 | 大荒囚天指、万剑归宗、吞日噬月功 |
| 顶级 | 涉及规则/因果 | 他化自在法、因果轮回道、天地同寿经 |

### 法宝/神器

**公式**：[材质/颜色/属性] + [器型]

- **兵器**：玄重尺、青冥剑、霜寒枪、裂天戟。
- **法器**：万兽鼎、混元塔、盘古幡、乾坤袋。
- **异火/天材**：青莲地心火、九幽冥火、紫瞳龙晶。

## ⚠️ 命名禁忌（严禁触碰）

1. **雅名堆砌晦涩字**：满是生僻字的名字是败笔，不是文化（如"龘靐烎"）。
2. **市井名低俗化**：接地气 ≠ 脏臭恶心（忌"狗剩"、"臭蛋"，可用"石根"、"栓柱"）。
3. **脱离人设乱起名**：草根逆袭者叫"慕容璟瑜"是灾难。
4. **无寓意直白名**：每个名字都要藏人设或命运伏笔，拒绝空洞。
5. **谐音梗**：搞笑文除外，严禁"范建"、"杜子腾"。
6. **西式译名**：修仙文里不要出现"杰克"、"汤姆"。

## 🛠️ AI 命名输出标准（必须遵守）

当需要为角色起名时，**必须按以下格式输出**：

```
【人物画像】
- 身份定位：[填写]
- 性格特质：[填写]
- 命运走向：[填写]
- 核心人设标签：[填写]

【命名结果】
1. 主名：[XX]；备选名：[XX]
2. 姓名拆解：
   - [字1]：[释义]
   - [字2]：[释义]
   - 整体寓意：[与人物命运的关联]
3. 风格归属：[雅韵类/市井类/道家类/武道类/文儒类/江湖类]
4. 音律解析：[标注平仄]，[说明顺口逻辑]
5. 配套雅号/俗号：[XX]（用于反差张力）
6. 适配依据：[结合人物画像，说明为何适配]
```

### 示例

```
【人物画像】
- 身份定位：草根出身，后成一方诸侯
- 性格特质：坚韧隐忍，重情重义，糙中带细
- 命运走向：从市井小贩逆袭为江湖侠士
- 核心人设标签：草根逆袭、铁骨柔情

【命名结果】
1. 主名：王栓柱；备选名：孙石根
2. 姓名拆解：
   - 栓：扎根市井，坚守本心
   - 柱：顶梁柱，有担当
   - 整体寓意：从市井根基做起，凭坚韧成为他人依靠
3. 风格归属：市井类
4. 音律解析：王栓柱（平平仄），顿挫有力，贴合草根侠士气场
5. 配套雅号：铁骨客
6. 适配依据：俗名贴合草根出身，"栓柱"寓意对应坚韧逆袭特质，雅号"铁骨客"呼应江湖侠士身份，形成反差张力
```

## 📝 快速检查清单

为角色起名后，对照以下清单：

- [ ] 名字是否匹配人物身份/性格/命运？
- [ ] 是否有文化出处或寓意？
- [ ] 平仄是否顺口？
- [ ] 风格归属是否清晰？
- [ ] 是否设计了反差（雅号/俗号）？
- [ ] 是否触犯禁忌区？
